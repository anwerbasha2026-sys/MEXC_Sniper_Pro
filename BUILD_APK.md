# Build the APK

This is the complete mobile project source. The included GitHub Actions workflow
builds `mexc-sniper-onn-gn3-armeabi-v7a-debug.apk`.

1. Put the project in a GitHub repository.
2. Open Actions and run **Build MEXC Sniper Android APK - Onn GN3 ARMv7**.
3. Download the generated workflow artifact named `mexc-sniper-onn-gn3-armeabi-v7a`.

The Android package includes the Kivy UI, LIVE scanner, MEXC account sync,
manual REAL SELL, configurable LIVE order/max order limits, SQLite recovery,
and the sticky foreground background service.
